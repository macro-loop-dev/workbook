# Chapter 0: reviewer notes

## Before the session

- Decide the Cursor plan question (student plan availability). If none, free
  tier for now; you pay Pro from chapter 8.
- Have his GitHub handle ready for the `share-library` skill config.
- Create `macro-loop-dev/workbook` on GitHub if the scaffold session could not
  (it could not: the session token had no org-level create permission).

## At the checkpoint

- Run the Check block yourself, over his shoulder. Every line answers.
- `gh repo clone macro-loop-dev/workbook ~\dev\workbook`, `cursor ~\dev\workbook`,
  double-click `index.html` in Explorer.
- Mark chapter 0 done in `index.html` in front of him, save, refresh. Say
  nothing about git.
- Ask him what each of the six tools is for. Accept guesses.

## Common mistakes

- Blue terminal. Always check the icon before anything else.
- Installed, not reopened. "Not recognized" after an install is PATH.
- SSH chosen in `gh auth login`. Start again with HTTPS.
- School email used for GitHub. Change the primary email now, not later.

## Deliberately not covered

Developer Mode, Docker, 1Password, Tailscale. If he asks about your setup,
show `dev-setup` on your laptop and say "later".
