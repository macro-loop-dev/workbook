The Workbook

This page is the workbook and the scoreboard. It is a website you are going to build, and the only thing that changes when you finish a chapter is one word in this file.

Every chapter ends the same way: you mark it done. What changes is how you are allowed to do that. In chapter 1 you edit this file by hand. By chapter 5 the edit goes through a pull request and deploys to a real website. By chapter 9 nothing in this file changes at all, because the answer lives in a database you built. That ladder is the whole course.

How to use this

Read a chapter top to bottom once before doing anything. Then do it, one numbered step at a time. Every chapter has the same nine sections in the same order, so by chapter 3 you will stop reading the headings.

Two other pages: the Library is things William thinks are worth your time, each with one line on why. The Notes are yours: a log of what you learned, cheat sheets you build as you go, and a glossary. Every chapter ends with one line in the log.

Deliberately not on this page

No JavaScript. No framework. No tracker. The counter above is drawn by CSS from the data-status attributes in this file, and that is all there is until chapter 7.
