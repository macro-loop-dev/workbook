The Workbook Chapters Library Notes

Library

Things William thinks are worth your time. Each one has a reason.

New items arrive as pull requests that you review and merge (from chapter 4). When you have looked at something, mark it seen: change its data-seen="no" to "yes", the same way you mark a chapter done. The new badge and the count above are drawn by CSS from that attribute.

Sites & apps to check out

  • FloatNote The app you will send a pull request to in chapter 11. Type some maths in it and watch the answer column.
  • Bartosz Ciechanowski's explainers Interactive explanations of how things work (GPS, cameras, bicycles). Every one is hand-built web code with no framework, which is the kind you are learning.
  • neal.fun Small, playful web toys. Proof that a website can be one idea done well.
  • Artificial Analysis: coding agent benchmarks This is a good resource for seeing benchmarks on how different models perform with different harnesses.

Tools

  • Cursor docs The editor you are using. Read the pages on Tab, Chat and Rules; the rest can wait.
  • GitHub CLI The gh command. From chapter 4 you open pull requests with it instead of clicking.
  • Excalidraw Draw a diagram before you build a thing. Free, no account, works in the browser.

Prompting & AI techniques

  • Simon Willison: how I use LLMs to help me write code The honest version. Set expectations, give context, test what it gives you. Chapter 2 in someone else's words.
  • Anthropic: prompt engineering overview Be clear, give examples, let it think. Written for people building with the API, but the first two pages apply to any chat box.

Reading & videos

  • MDN: Learn web development The reference for HTML, CSS and JavaScript. When the AI tells you what a tag does, this is where you check.
  • The Missing Semester of Your CS Education A course on the terminal, git and the tools around code. Chapter 3 and 4 material, taught by MIT for free.
  • Julia Evans' zines Comics that explain git, the terminal and networking. Read the free ones first.

Deliberately not here

Nothing you have to read to finish a chapter. The chapters are self-contained; the Library is the part after.
